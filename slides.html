Data Ingestion & Engineering Challenges Solved

Real-world messy data pipelines require strict geospatial harmonization, robust sanity checks, and schema reconciliation.

Problem 1: Multi-Resolution Grids

Raster Dimension Disparity

GSA GeoTIFFs arrived at vastly different native dimensions: GHI/DNI at $12,800\times12,800$, PVOUT/TEMP at $3,840\times3,840$, and OPTA at $960\times960$.

Solution: Exact coordinate projection bounding box transforms and bilinear spatial sampling across 77 ground station centroids.
Problem 2: Maharashtra Name Updates

Administrative Discrepancies

Recent official renamings created silent join drops (Ahmednagar $\rightarrow$ Ahilyanagar, Aurangabad $\rightarrow$ Chh. Sambhajinagar, Osmanabad $\rightarrow$ Dharashiv).

Solution: Built a comprehensive bidirectional name reconciliation dictionary with automated pre-merge row assertions (34 / 34 districts verified).
Problem 3: Telemetry Sensor Noise

Spurious Sensor Readings

Raw telemetry feeds included unphysical negative rainfall and saturated 100%+ humidity spikes caused by station line faults.

Solution: Enforced domain physical bounding filters ($0 \le \text{Rain} \le 300\text{ mm}$, $5\% \le \text{RH} \le 100\%$, $0 \le \text{Wind} \le 80\text{ km/h}$) before aggregation.

⚠️ Honest Technical Limitations

  • Macro vs Parcel Siting: Model evaluates district and taluka macro-suitability; actual micro-siting requires cadastral village land surveys for exact parcel shapes.
  • Substation Headroom: Model measures physical distance to substations; actual spare MVA transformer capacity must be verified with MahaTransco.
  • Dynamic Dust / Soiling: Agricultural harvesting seasons introduce temporary dust deposition on modules requiring local wash schedules.
  • Land Title & Forest Clearances: Actual procurement depends on local revenue land records and non-forest demarcation.
